# bank_pokypok_3_html

Одностраничный MVP-проект на **HTML + JS** для концепции «Банк покупок».

## Что внутри
- Главная страница с быстрым выбором: покупка или квест.
- Каталог товаров и выбор оплаты: **SberPay / VTB Pay** (демо-заглушка API).
- Квест на 5 уровней с прогресс-баром.
- Загрузка фото/видео подтверждений по уровням.
- QR-сканер (через `html5-qrcode` CDN).
- Профиль с прогрессом и рассчитанной наградой.
- Мультиязычность: `RU / EN / MAR`.
- Палитра: `lightgreen`, `lightyellow`, `lightpink`.

## Запуск
Открой `index.html` в браузере
или запусти локальный сервер:

```bash
python3 -m http.server 8080
```

И открой: <http://localhost:8080>
