# bank_pokypok_3_html

Квест-проект на **HTML + JS** с простым backend для хранения прогресса пользователя.

## Реализовано
- Квест из 5 уровней:
  1. фото зелёного объекта
  2. фото орнамента + вопрос
  3. видео в магазине
  4. фото с человеком
  5. финальный вопрос
- Прогресс: `1/5`, `2/5` ... `5/5`.
- Переход между уровнями кнопками "Назад / Следующий уровень".
- UI карточек заданий.
- QR scanner (html5-qrcode) + кнопка "Сканировать".
- Логика QR:
  - QR в формате `LEVEL-<номер>` открывает нужный уровень.
  - Проверка доступа: нельзя открыть уровень выше максимально доступного.
- Backend API для хранения прогресса пользователя (`GET/POST /api/progress/:userId`).

## Запуск
```bash
node server.js
```

Открой: <http://localhost:8080>

## Хранение данных
Прогресс хранится в файле `data/progress.json`.
